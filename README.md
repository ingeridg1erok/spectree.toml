# Trechos que chamaram atenção no material

O autor abre o material explicando que a linguagem roda sobre a máquina virtual do Erlang.

Ela foi criada por um desenvolvedor brasileiro.

É mais simples de escrever do que o Erlang.

Aproveita melhor os vários núcleos de um processador do que a maioria das linguagens por aí.

Um exemplo de eficiência citado em aula: um serviço de mensagens conhecido mantém um servidor escrito nessa linguagem atendendo milhares de conexões ao mesmo tempo usando só metade da capacidade de processamento.

Outro ponto destacado foi a comunicação entre processos por troca de mensagens, e a possibilidade de trocar código com o sistema rodando — sem precisar derrubar nada.

### Observacao

Este trecho foi anotado durante os estudos e nao substitui a documentacao oficial.
